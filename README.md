# TcsForge — Releases

This repository hosts the official releases of **TcsForge**, a streamer toolkit for Twitch.

## Download

Head to the [Releases](../../releases) page and download `TcsForge-win-Setup.exe` to install.

## Auto-update

Once installed, TcsForge will automatically notify you when a new version is available.
You can also check manually in **Settings → About → Check for updates**.

## Requirements

- Windows 10 or later
- Internet connection for Twitch authentication
